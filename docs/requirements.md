## 1. 产品定位

一个**自用工具类 App**：在地图上选一个位置，把它注入 Android 系统位置服务，
让其他地图 / 打卡类 APP 认为你就在那里；并给出「注入是否被对方接受」的可视化反馈与自动校准。

目标用户：需要在不修改他人 APP 的前提下验证位置相关行为的开发者 / 测试人员本人。
**非**面向公众分发的商业产品（不上架、不做账号体系、不做多用户）。

---

## 2. 名词约定

| 缩写 | 全称 | 含义 |
|------|------|------|
| UL | User Location | 用户在地图上选中的点（主观意图），蓝扎标 |
| ML | Mock Location | 实际注入系统的坐标，反推校准会迭代调整它 |
| AL | AMap Location | 高德定位 SDK「看到的」位置（可能被反 mock / 风控加工），紫扎标探针 |
| Test Provider | — | Android `LocationManager.addTestProvider` 注册的模拟位置提供者 |

## 3. 功能需求（FR）

### FR-1 地图显示与交互
- 加载高德地图，支持缩放 / 拖动 / 旋转 / 倾斜。
- 点击或长按地图 → 取该点经纬度 → 逆地理编码补全地址 → 显示「已选位置」气泡（名称 / 经纬度 / 地址 / 关闭按钮）。
- 滚动地图时气泡立即消失；再次点击 / 长按重新出现。
- **验收**：真机上地图可正常渲染、可拖动缩放；点选后气泡内容含 6 位小数经纬度与中文地址。

### FR-2 定位与「我的位置」
- 启动时自动申请定位权限（精确定位 `locationWhenInUse`），拿到后地图自动移动到当前位置并显示**绿色车标**（常驻）。
- 右下角 FAB「回到当前位置」：重新定位并跳图，同时补画绿车标。
- 「显示当前位置」按钮：以 `SnackBar` 播报「当前位置是 XXX」。
- 定位数据源优先级：系统主动定位 `requestRealLocation`（8s 超时）→ 高德 SDK 回调缓存 → 系统 `getLastKnownLocation` 缓存。
- 模拟运行期间禁止上述操作，提示「请先停止模拟……」。
- **验收**：室内冷启动 5s 内能拿到位置（否则给出明确排查提示）；绿车标与高德蓝点基本重合。

### FR-3 关键字搜索
- 顶部搜索框输入时 300ms 防抖请求高德「输入提示」接口，结果显示在搜索框下方，点选即选中该 POI（蓝扎标 + 气泡 + 跳图）。
- 点「搜索」或键盘回车：0 条提示「未找到」；1 条直接采用；多条弹底部列表由用户选择。
- 搜索命中的地点与地图点选走**同一套选中逻辑**（可保存、可应用到系统）。
- **验收**：输入「天安门」能联想出候选；选中后地图跳转且气泡显示 POI 名称。

### FR-4 收藏与历史
- 「保存」按钮：弹出对话框（可改名，最多 30 字），保存当前 UL；上限 **10 条**，超出时提示「已达到 10 个收藏上限」。
- 「历史」按钮：全屏列表，按保存时间倒序；每行显示名称 / 经纬度 / 保存时间，点击展开。
- 展开行操作：**Go**（地图跳过去）、**Delete**（删除）、**Run**（跳图 + 应用到系统）、**always** 复选框（全局单选，启动时自动应用该书签）。
- 空列表显示「还没有保存的位置」。
- 存储：`SharedPreferences`，key `location_bookmarks_v1` / `location_bookmarks_always_id_v1`。
- **验收**：保存 11 条时第 11 条被拒绝并提示；重启 App 后收藏与 always 勾选保持；勾选 always 后冷启动自动进入模拟。

### FR-5 模拟位置注入（Android）
- 「应用到系统」：检查「模拟位置应用」授权 → 未授权则跳转开发者选项并提示 → 已授权则启动原生**前台服务**持续注入位置。
- 注入频率 500ms；同时注册 `GPS_PROVIDER` 并可镜像到 `NETWORK_PROVIDER`。
- 注入的 Location 携带递增的 `elapsedRealtimeNanos`、`time`、`accuracy=5`、`speed/bearing`、以及 `extras`（`satellites`/`maxCn0`/`distance`/`bearing`）。
- 模拟期间地图锁定（手势 + 点选关闭），按钮变为「停止模拟」，并弹出「模拟状态」对话框。
- 「停止模拟」：停止前台服务、移除 Test Provider、解锁地图、关闭对话框、清除探针状态。
- **验收**：模拟期间打开第三方地图 APP，显示位置为所选点（或经校准逼近）；
  通知栏可见前台服务通知；停止后第三方 APP 恢复真实定位。

### FR-6 AL 探针（反 mock 观测）
- 模拟启动后，用**高德独立定位 SDK**（`AMapLocationClient`，`setMockEnable(true)`，8s 超时）主动探一次「高德视角」位置。
- 探针失败最多重试 3 轮（间隔 3s）；全部失败提示「疑似被风控」。
- 探针结果以**紫色 pin** 叠加显示；探针位置与 UL 的距离（Haversine，米）实时显示在状态对话框「位置校准」行。
- **验收**：模拟后 5~10s 内紫 pin 出现（或被明确提示风控）；偏差值与实际地理差异吻合。

### FR-7 反推校准
- 当首轮偏差 > 50m 时自动启动校准循环：第 *i* 轮注入 `ML_i = 2·UL − AL_{i-1}`。
- 参数：最多 **4 轮**、每轮间隔 **6s**、收敛阈值 **50m**、单步限幅 **10km**、
  「连续两轮偏差变化 < 1m」判定为风控、`readAlProbe` 连续 2 次返回 null 判定为风控（第 1 轮宽容）。
- 进度实时显示：`推理校准中 i/4… 偏差 xx m` → 成功显示 `推理完成，残余偏差 x m（推理前 y m）`；
  失败显示原因（疑似风控 / 达最大迭代次数 / SDK 未响应）。
- 对话框标题在 mock 生效且无需/已完成校准时变为「已就绪」。
- **验收**：偏差 > 50m 时状态对话框能观察到轮次推进；收敛后残余偏差 < 50m；被风控时给出明确原因而非静默失败。

### FR-8 状态可视化
- 「模拟状态」对话框实时展示三块信息：① 模拟状态（未启用 / 准备中 / 运行中 / 出错原因）；
  ② 位置校准偏差（< 50m 绿、< 300m 橙、其余红）；③ 推理状态。
- mock 状态回到 idle 时对话框自动关闭；用户可手动关闭且不影响模拟运行。
- **验收**：对话框随模拟启动弹出、停止消失，数值实时刷新。

### FR-9 平台与降级
- 非 Android 平台（iOS / 桌面）调用 mock 等相关接口不得崩溃（`MissingPluginException` 被捕获，返回失败语义）。
- **验收**：桌面端可启动 UI，点击「应用到系统」给出可读提示而非崩溃。

## 4. 非功能需求

| 项 | 要求 | 现状 |
|----|------|------|
| 性能 | 地图操作无明显卡顿；500ms 推送循环不阻塞 UI（原生线程 + WakeLock） | 已实现 |
| 功耗 | 模拟期间持有 `PARTIAL_WAKE_LOCK`，停止后释放 | 已实现 |
| 后台存活 | 退到后台不被 ROM 冻结（前台服务 + WakeLock，针对华为鸿蒙节能策略） | 已实现 |
| 可维护性 | 地图厂商经 `MapStrategy` 隔离；页面不直接依赖高德 SDK | 已实现（`home_page.dart` 仅多 import 了 `AMapStrategy.initWithContext`） |
| 安全 | 高德 Key 不应硬编码进公开仓库 | ⚠️ 源码已改为构建期注入（`--dart-define-from-file`，无明文 Key）；**历史提交中的旧 Key 仍需在高德控制台轮换** |
| 测试 | 关键纯逻辑（反推公式、Haversine、收敛判定）应有单测 | **未达成**（仅占位测试） |

## 5. 边界与非目标

**边界（明确不支持 / 有前提）**
- 模拟位置仅 Android 可用，且**必须真机**（需 Root 或开发者选项授权「模拟位置应用」）。
- 无法绕过系统级 `isFromMockProvider` 判定：部分 APP（高德、大众点评等）会识别并降权，本项目只能"逼近"。
- 逆地理编码 / 搜索依赖网络与高德 Web 服务 Key 配额。
- 收藏上限 10 条；不做导入导出、不做云同步。

**非目标（本期不做）**
- iOS、鸿蒙（HarmonyOS NEXT / OpenHarmony）原生实现。
- 账号体系、多设备同步、分享。
- 轨迹模拟 / 沿路径移动（当前只做单点静态注入）。
- 应用商店上架与商业化。
